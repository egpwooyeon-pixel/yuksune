# EGP AI 스튜디오 제품 계획

> 이 문서는 개발하면서 계속 고쳐요. 정해지지 않은 것은 `DECISIONS.md` 에 모아 둬요.

## 한 줄 정의
업체가 **AI 검색 답변에 어떻게 소개되는지 진단**하고, 업체 정보를 바탕으로 한 **안내 글을 정리·발행**해 AI와 검색에서 근거로 쓰이도록 돕는 서비스.

## 방문자 흐름
1. **랜딩** (`landing.html`): 서비스 설명, 레퍼런스, 상담 신청
2. **AI 진단** (`diagnose.html`): 홈페이지 주소 → 업체 정보 자동 채우기 → 진단 리포트
3. **발행 설정** (`diagnose.html` 아래, `ORDER_UI`): 상품·수량·기간 선택 → 상담 신청으로 전달
4. **상담 → 접수** (운영자가 확인)
5. **글 작성·검수·발행** (운영자 화면) → **정보 가이드** (`/guide/`) 에 공개

## 상태 (단계별)
| 단계 | 내용 | 상태 |
|---|---|---|
| A | 랜딩·진단 화면·자동 채우기·발행 설정 입력란 | 완료 (스위치로 켜고 끔) |
| B | 정보 가이드 글 템플릿·생성기 | 완료 (예시 글만) |
| C | 신청 접수 저장 (DB) + 관리자 접수 목록 | 코드·시험 완료 (Supabase 에 021 SQL 실행 필요, 스위치 꺼짐) |
| D | 업체 사진 보관함 (비공개) | 진행 |
| E | 글 초안 생성(Gemini) + 운영자 검수·승인 | 진행 (Gemini 연결은 모델 과부하로 보류) |
| F | 승인된 글 공개 발행 | 설계 |
| G | 결제·일정 자동 발행 | 보류 (결정 필요) |

## 원칙 (개발자가 혼자 진행할 때도 지킴)
- **사람의 승인 없이 글이 공개되지 않아요.** 생성(초안) → 검수 → 승인 → 발행.
- 글에는 **업체가 제공한 정보와 확인된 출처만** 써요. 효능·가격·후기·순위를 지어내지 않아요.
- 병원·의료 글은 의료광고 규정과 사실 확인을 거치기 전에는 발행하지 않아요.
- 모든 글에 광고 표시를 붙이고, 검색 노출(`indexable`)은 기본 꺼짐이에요.
- 새 기능은 **스위치(`landing-config.js`)로 꺼진 채로 합쳐요**, 외부 호출·비용이 드는 기능은 기본 꺼짐.
- 비밀키는 저장소에 넣지 않아요 (Supabase Secrets 에만).
- 다른 회사의 상품명·가격·홍보 문구·문장을 가져오지 않아요.

## 기술 구조
- 화면: 빌드 없는 정적 HTML/CSS/JS (Netlify). 서버: Supabase (DB + Edge Functions).
- 글 공개: 지금은 정적 파일 생성기(`tools/build-guides.mjs`). 승인된 글을 자동 공개하려면 Netlify Function 으로 서버에서 HTML 을 그리는 방식을 검토 중 (키 없이 가능, 배포 환경 확인 필요).
