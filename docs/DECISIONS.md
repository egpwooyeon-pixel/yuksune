# 정해야 할 것 (사용자 결정 필요)

개발자(Claude)가 임의로 정하지 않고 비워 둔 것들이에요. 정해지면 알려 주세요.

## 사업·상품
- [ ] 상품 구성과 **건당 단가** (`landing-config.js` 의 `ORDER.products`). 다른 회사 가격을 쓰지 않아요.
- [ ] 결제 방식 (카드/계좌이체/세금계산서). 결제 연동은 사업자 정보와 PG 계약이 필요해요.
- [ ] 발행 전 **누가 검수·승인**하는지 (EGP 운영자 / 업체 확인 포함 여부)

## 법·정책
- [ ] **개인정보 보호책임자** (`config.js` 의 `COMPANY.privacyOfficer`)
- [ ] 개인정보 **보관 기간** (상담 문의, 진단 결과, **업체 사진**). 사진은 기록을 지워도 파일이 남아서, 자동 삭제 방식도 정해야 해요
- [ ] **병원 레퍼런스 사용 동의** (동의 전에는 `SHOW_REFERENCE: false` 권장)
- [ ] 의료·법률 업종 글의 발행 기준과 문구(광고 표시 등) 전문가 검토

- [ ] 사진 업로드 정책: 사람 얼굴이 나온 사진을 받을지(기본은 받지 않음), 올린 사진을 글에 쓸 때 업체에 확인받을지

- [ ] **글 자동 검사 금지어 목록**(`aeo-draft` 의 BLOCK_TERMS/WARN_TERMS)과 AI 지시문(프롬프트)을 업종별로 전문가와 검토 (병원·의료 업종 우선)
- [ ] 글 승인 기준: 검수자가 확인해야 할 체크리스트(업체 확인 여부, 사실 대조, 광고 표시)

- [ ] **진단 리포트의 "콘텐츠 발행 제안"을 방문자에게 얼마나 무료로 보여 줄지**(지금은 주제·형식·순서·자료 전부). 일부만 보여 주고 나머지는 상담 후 제공할 수도 있어요
- [ ] 의료 업종의 제안 규칙(시술명·효과·후기·가격이 든 주제 제외)이 의료광고 규정 면에서 충분한지, 완화할 수 있는지 전문가 확인

## 해외 진단 보고서 (overseas-report.html)
- [ ] 지금 화면의 병원·경쟁사·수치는 **전부 가상의 예시**예요. 실제 고객에게 전달하려면 `overseas-report-data.js` 를 측정 결과로 바꿔야 해요(검색량·순위는 외부 도구로 직접 측정해야 하며, 이 사이트가 자동으로 측정하지 않아요)
- [ ] 이 예시 페이지를 사이트 메뉴(랜딩 상단 "해외 진단")에 공개해 둘지, 고객별 비공개 링크로만 쓸지
- [ ] 병원 고객 대상 문구(효과·후기·가격 표현)의 의료광고 규정 적합성 전문가 확인
