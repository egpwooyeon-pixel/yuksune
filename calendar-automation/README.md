# 방문 일정 자동 등록 (구글 시트 → 구글 캘린더 + 고객 초대 메일)

시트에 일정을 입력하고 **상태를 `등록대기`로 바꾸면** 구글 캘린더에 등록되고, **이메일 칸의 고객에게 캘린더 초대 메일이 자동 발송**됩니다.

## 설치 (약 5분, 최초 1회)

1. 새 구글 시트를 만든다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다.
3. `Code.gs` 내용을 전부 지우고 이 폴더의 `Code.gs`를 붙여넣는다.
4. (선택) 왼쪽 ⚙ **프로젝트 설정 → "appsscript.json 매니페스트 파일 표시"** 를 켜고, 이 폴더의 `appsscript.json` 내용으로 교체한다. 시간대(Asia/Seoul)와 권한 범위가 설정된다.
5. 저장 후 시트를 새로고침하면 상단에 **📅 방문일정** 메뉴가 생긴다.
6. **① 시트 초기 설정** 실행 → 권한 승인(캘린더, 시트, 트리거) → `방문일정` 시트가 양식대로 만들어진다.
7. **② 자동 실행 켜기** 실행 → 끝.

> "확인되지 않은 앱" 경고가 뜨면 본인이 만든 스크립트이므로 *고급 → 이동*으로 진행한다.

## 사용법

| 열 | 입력 | 비고 |
|---|---|---|
| 고객명 / 구분 / 방문일 / 시작 / 종료 / 연락처 / 이메일 / 장소 | 직접 입력 | 종료를 비우면 시작+60분. 이메일은 `,`로 여러 개 가능 |
| **상태** | 드롭다운 | **마지막에 입력.** 이 칸이 바뀔 때만 처리됨 |
| 이벤트ID / 처리결과 | 자동 기록 | 건드리지 않기 |

| 상태 값 | 동작 |
|---|---|
| `등록대기` | 캘린더 등록 + 이메일 있으면 초대 메일 발송 → `등록완료` |
| `수정대기` | 이벤트ID의 일정을 시트 내용으로 수정 (고객 추가/제거 포함) |
| `취소요청` | 캘린더 일정 삭제 → `취소됨` |
| `오류` | 입력 문제. **처리결과 칸**에 이유가 적힘. 고친 뒤 다시 `등록대기` |

자동 검증: 고객명 필수, 날짜·시간 형식, 종료>시작, **연락처 형식**(예: `10-6458-206` 같은 오류 차단), 이메일 형식, 지난 일정 차단. 같은 시간대에 다른 방문 일정이 있으면 `처리결과`에 ⚠ 경고만 표시하고 등록은 진행한다.

## 운영 전 반드시: 테스트

1. `Code.gs` 상단 `CONFIG.TEST_EMAIL`에 **본인 다른 이메일**을 넣는다. 모든 초대가 그 주소로만 간다.
2. 시트에 일정 한 줄을 넣고 상태를 `등록대기`로 바꾼다. 캘린더 등록, 메일 도착, 수정, 취소를 각각 확인한다.
3. 확인되면 `TEST_EMAIL`을 `''`로 비운다.

## 설정 (`Code.gs` 상단 CONFIG)

- `CALENDAR_NAME`: 전용 캘린더 이름 (비우면 기본 캘린더)
- `TITLE_PREFIX`: 제목 머리말 (기본 `[브레디트 방문]`)
- `REMINDER_MINUTES`: 내 캘린더 팝업 알림 (기본 120분 전)
- `SEND_INVITES`: `false`면 메일 없이 캘린더에만 등록
- `GUEST_NOTE`: 초대장에 덧붙일 안내문. **고객에게 그대로 보이는 내용**이다

## 알아둘 점

- 고객에게 가는 메일은 **구글 캘린더 초대장**이다(수락/거절 버튼 포함). 맞춤 문구의 별도 메일이 필요하면 `MailApp.sendEmail`로 확장할 수 있다.
- **[확인 필요]** 일정 *수정*과 *취소* 때 고객에게 변경/취소 알림이 실제로 가는지는 계정·설정에 따라 다를 수 있어 직접 테스트로 확인해야 한다.
- 구글 계정의 일일 메일/초대 발송 한도가 있다. 대량 발송 전 [Apps Script 할당량 문서](https://developers.google.com/apps-script/guides/services/quotas)를 확인한다.
- 이벤트ID 칸을 지우면 중복 방지가 풀려 같은 일정이 다시 등록될 수 있다.
- 시트에서 직접 지운 행의 캘린더 일정은 자동 삭제되지 않는다. 삭제는 `취소요청`으로 한다.
- `sample.csv`는 시트 머리글/예시 한 줄이다 (가져오기용, 예시 데이터는 가짜).
