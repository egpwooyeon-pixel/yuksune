사장님이 올린 사업자등록증은 "서류 보기"로 확인하고 승인 또는 반려하세요. 서류는 확인 후 "서류 삭제"로 지울 수 있어요. 승인된 회원만 체험단을 등록할 수 있어요.

커뮤니티 가입 신청 인플루언서·대행사 커뮤니티는 승인된 회원만 들어갈 수 있어요. 신청을 확인해 승인하거나 반려하세요.
    승인된 회원 유형을 바꾸거나 해제할 수 있어요. 해제하면 그 커뮤니티의 글·댓글이 바로 보이지 않아요.

        NAVER PLACE

        네이버 플레이스

        업플로우에 등록된 키워드의 순위를 읽어 와요. 페이지를 열거나 새로고침해도 새로 조회하지 않아요.

        오늘 확인할 항목

          키워드 등록 · 대량 등록

          한 줄에 키워드, 플레이스 주소 또는 ID를 입력하세요. 한 번에 최대 50줄이에요. 먼저 중복 확인으로 이미 추적 중인 키워드를 찾고, 새로 등록할 것만 보내요. 등록은 업플로우의 추적 슬롯을 사용하고, 쓰기 권한이 있어야 해요.

          1회 검색

          버튼을 눌렀을 때만 실제로 검색해요. 업플로우 웹과 조회 한도를 함께 쓰니 필요할 때만 눌러 주세요.

          같은 키워드·같은 검색 조건으로 업플로우 계정에 등록된 추적 매장끼리만 비교해요. 계정에 없는 경쟁 매장은 보이지 않아요.

          웹훅 연결 정보 (선택 · 놓쳐도 '목록 다시 읽기'로 따라잡아요)

          웹훅은 업플로우가 "이 키워드의 이력이 바뀌었어요"라고 알려 주는 신호예요. 받은 신호는 순위 데이터를 저장하지 않고, 해당 키워드의 이력을 다시 읽도록 표시만 해요. 실패한 전달은 업플로우가 다시 보내지 않아요.

          • 받는 주소:
          • 받는 이벤트: rank.changed · refresh.completed · refresh.failed
          • 서버 비밀값 이름: UPFLOW_WEBHOOK_SECRET (Supabase > Edge Functions > Secrets)
          • 마지막 수신: 확인 중…

          위 주소를 업플로우 개발자 페이지에서 직접 등록해 주세요. 이 화면은 웹훅 등록 요청을 보내지 않아요. 서명(X-UpFlow-Signature)이 맞지 않거나 이미 받은 전달(X-UpFlow-Delivery)은 처리하지 않아요.

            직접 부과
            페널티 1회=등록 7일 정지, 2회=30일 정지, 3회 이상=영구 정지. 미선정 5회는 자동으로 페널티 1회가 돼요.
            매장·캠페인 연결

            "연결 해제"는 우리 사이트의 매장·캠페인 연결만 지워요. 업플로우의 추적에는 영향이 없어요.

            업플로우에서 (별도 작업)

            추적 중지와 휴지통 이동은 업플로우 웹에서 해 주세요. (공식 API 문서를 확인하지 못해 이 화면에서는 실행하지 않아요)
