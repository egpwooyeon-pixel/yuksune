# 글 초안 생성·검수 설정

운영자가 업체 정보와 **확인된 사실**을 넣으면 AI(Gemini)가 정보 가이드 글 **초안**을 쓰고, 운영자가 검수해서 **승인**하는 기능이에요.
화면: 관리자 > **글 초안 (EGP)** (`admin-drafts.html`). 이 기능은 **글을 공개하지 않아요.** 승인된 글만 다음 단계(공개 발행)로 넘어가요.

## 원칙 (코드에 들어 있어요)
1. **AI는 초안만.** 승인은 운영자가 **검수 메모(5자 이상)**를 남겨야 하고, 승인한 사람·시각이 기록돼요.
2. **입력한 사실과 출처만.** AI에게 "제공된 사실만 쓰고, 효과·가격·후기·순위·보장 표현을 쓰지 말라"고 지시하고, 사실이 2개 미만이면 만들지 않아요(지어내기 방지).
3. **출처 링크·업체 정보·날짜·주소(slug)는 AI가 아니라 서버가 채워요.** AI가 만든 링크나 연락처는 글에 들어가지 않고, 운영자가 수정 화면에서 바꿀 수도 없어요.
4. **자동 검사**를 만들 때와 수정 저장할 때마다 다시 해요.
   - **차단**(승인 불가): 과장·보장·최상급·의료 결과·전후·후기·할인 표현(예: 최고, 1위, 보장, 완치, 후기, 할인), 입력에 없는 전화번호
   - **확인**(경고): 입력에 없는 숫자(원·%·명·년 등)·링크, 효과 단정 표현, 글이 너무 짧음
   - 입력한 사실에 **이미 들어 있는 표현은 자동으로 막지 않아요.** 그 표현이 법·규정상 괜찮은지는 사람이 확인해야 해요.
5. 병원·의료·법률 글은 의료광고 규정 등 **전문가 검토 없이 공개하지 마세요.** 이 자동 검사는 규정 준수를 보장하지 않아요.

## 구성
| 파일 | 역할 |
|---|---|
| `supabase/025_drafts.sql` | 초안 표(`guide_drafts`). 브라우저는 **읽기만**(운영자), 쓰기는 서버 함수와 승인 함수로만. `review_guide_draft`: 운영자만·메모 필수·초안 상태에서만·차단 항목 있으면 승인 불가 |
| `supabase/functions/aeo-draft` | 초안 만들기(`generate`)와 수정 저장(`save`). **운영자 로그인 확인**, Gemini 호출, 자동 검사 |
| `admin-drafts.html/.js` | 목록, 새 초안, 본문 수정, 자동 검사 결과, 검수 메모·승인·반려 |

## 켜는 순서
1. Supabase SQL Editor 에서 `supabase/025_drafts.sql` 실행 (008·021 이후). 여러 번 실행해도 안전해요.
2. `aeo-draft` 함수 배포. 비밀값 `GEMINI_API_KEY` 가 필요해요(진단 기능과 같은 것). 모델은 `GEMINI_MODEL`(쉼표로 여러 개 가능, 기본 `gemini-3.8-flash`).
   - JWT 확인은 **켜진 기본값** 그대로 두세요. 함수 안에서 한 번 더 운영자인지 확인해요.
3. 관리자로 로그인 → **글 초안 (EGP)** → **새 초안 만들기**.
4. 처음에는 가상 업체로 시험해 보고, 자동 검사 문구가 기대대로 나오는지 눈으로 확인하세요.

## 상태
- `025_drafts.sql`: 임시 PostgreSQL 16 에서 승인 규칙(권한·메모·차단·이중 검수·직접 쓰기 차단)을 시험했어요. 단, 이 환경에는 Supabase 의 `auth` 스키마가 없어서 `auth.uid()` 를 **가짜 함수로 대체**해 시험했어요.
- `aeo-draft`: 모의 Gemini 로 입력 검사, 지어낸 출처·전화번호 차단, 자동 검사, 수정 저장 규칙, 운영자 확인, 모델 전환(404)을 시험했어요. 이 함수의 검증은 `tools/build-guides.mjs` 의 검증과 같은 결과를 내는지 시험으로 확인했어요(같은 규칙이 두 군데에 복사돼 있어서, 한쪽을 고치면 다른 쪽도 고쳐야 해요).
- 화면: 모의 서버로 권한·XSS·목록·수정·저장·승인/반려·차단 초안·읽기 전용·오류 문구를 시험했어요.
- **실제 Gemini 와 실제 Supabase 로는 실행해 보지 않았어요.** 실제 AI 가 쓴 글이 규칙(사실만, 과장 없음)을 얼마나 지키는지는 첫 실행에서 확인해야 해요. 금지어 목록은 시작점일 뿐이고, 실제 글을 보며 다듬어야 해요.
