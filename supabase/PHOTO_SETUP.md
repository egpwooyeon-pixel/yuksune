# 업체 사진 보관함 설정

진단 화면의 **업체 사진** 카드로 받은 사진을 **비공개**로 저장하고, 운영자만 보게 하는 기능이에요.
끝내기 전에는 `landing-config.js` 의 `PHOTO_UPLOAD_LIVE` 를 `false` 로 두세요(카드가 숨겨져요).

## 어떻게 동작하나요
1. 방문자가 사진(최대 3장, JPG/PNG/WebP, 장당 4MB)을 고르면, 화면이 **파일 앞부분으로 실제 형식**을 확인해요(이름·확장자는 믿지 않아요).
2. 서버 함수 `aeo-photo` 가 한도를 확인하고, **서버가 정한 경로**(`<묶음번호>/<무작위>.jpg`)로 **일회용 업로드 토큰**을 줘요.
3. 화면이 그 토큰으로 비공개 버킷 `business-photos` 에만 올려요. 방문자는 저장소에 직접 쓰거나 읽을 수 없어요.
4. 올린 **묶음 번호**가 상담 신청에 함께 저장돼요(`inquiries.photo_batch`).
5. 운영자는 관리자 > 상담 접수 에서 **사진 보기**를 누르면 2분짜리 임시 주소로 열어요.

## 지켜지는 제한
- 형식·용량: 버킷 설정이 저장소 쪽에서 강제 (JPG/PNG/WebP, 4MB). 화면 검사는 편의일 뿐이에요.
- 한도: 묶음 하나 3장, IP(해시값) 하루 9장, 전체 하루 200장 (`PHOTO_IP_DAILY`, `PHOTO_DAILY_LIMIT` 로 조정).
- 원본 IP 는 저장하지 않고 해시값만 저장해요.
- 올리는 사람에게 "사용 권한이 있고, 사람의 얼굴·연락처 등 개인정보가 보이지 않는 사진"이라는 확인을 받아요.

## 켜는 순서
1. `supabase/021_inquiries.sql` 실행 (아직이라면) → `supabase/024_photos.sql` 실행.
   - 24번은 버킷(`business-photos`, 비공개)과 표·권한·함수를 만들어요. 여러 번 실행해도 안전해요.
2. Edge Functions 에 `aeo-photo` 를 만들고 `supabase/functions/aeo-photo/index.ts` 를 배포 (JWT 확인은 켜진 기본값).
3. Supabase > Storage 에서 버킷 `business-photos` 가 **Private** 인지, 크기 제한 4MB·허용 형식이 맞는지 눈으로 확인.
4. 개인정보 **보관 기간**을 정하고 `landing-privacy.html` 의 노란 표시를 고쳐요. (정하기 전에는 켜지 않는 것을 권해요)
5. `landing-config.js` 에서 `PHOTO_UPLOAD_LIVE: true` 로 바꾸고 사이트를 다시 올려요.
6. 진단 화면에서 사진 1장을 올려 보고, 관리자 > 상담 접수 에서 **사진 보기**가 열리는지 확인해요.

## 알아둘 것
- **파일 삭제**: 표의 기록을 지워도 저장소의 파일은 지워지지 않아요. 파일은 Supabase Storage 화면이나 Storage API 로 지워야 해요. 자동 삭제(보관 기간 지난 사진)는 아직 없어요.
- 형식 확인은 파일 앞부분 검사와 버킷의 형식 제한이에요. 이미지처럼 보이는 가짜 파일을 완전히 막지는 못해요. 운영자가 여는 임시 주소는 새 창에서 열리고 2분 뒤 만료돼요.

## 상태
- `024_photos.sql`: 임시 PostgreSQL 16 에서 한도·형식 거부·경로 생성·권한을 시험했어요. 단, 이 환경에는 Supabase 의 `storage` 스키마가 없어서 **최소한의 가짜 `storage` 스키마**로 시험했어요(버킷 설정과 `storage.objects` 정책의 실제 동작은 Supabase 에서 확인이 필요해요).
- `aeo-photo`: 모의 응답으로 입력 검사·한도·서명 흐름을 시험했어요.
- 화면: 모의 서버로 파일 검사(가짜 이미지·4MB 초과·4장 초과)·동의·업로드·부분 실패·랜딩/관리자 연결을 시험했어요.
- **실제 Supabase Storage 로는 실행해 보지 않았어요.** 서명 업로드 주소 발급 요청(`POST /storage/v1/object/upload/sign/<bucket>/<path>`)과 브라우저의 `uploadToSignedUrl` 사용은 공식 문서 형식을 기준으로 가정했으니, 첫 실행 때 확인이 필요해요.
